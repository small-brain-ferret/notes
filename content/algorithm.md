> [!NOTE] Algorithm
> An algorithm is a well-defined computational procedure
>
> - comprises a set of instructions that
> - takes some value as input, and
> - produces a value (or a set of values) as output
>
> An algorithm must be
>
> - exact
> - effective
> - general
> - and must terminate
