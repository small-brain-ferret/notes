> [!NOTE] Definition
> Initial conditions (ICs) are specified at a single value of the independent variable.
>
> ie. for an ODE with variables $x$, $y$:
> $y=1$ and $\frac{dy}{dx} = 3$ forms a set of ICs.

An [[Initial value problem (IVP)]] is an [[Ordinary differential equation]] with ICs. These will result in a particular solution rather than a general one.
