The [[Hessian Matrix]] is useful in [[Characterising critical points]].

| Condition                                                                                | Classification    |
| ---------------------------------------------------------------------------------------- | ----------------- |
| $\det(H) > 0$, $\frac{\partial^2 f}{\partial x^2},\frac{\partial^2 f}{\partial y^2} > 0$ | Local minimum     |
| $\det(H) > 0$, $\frac{\partial^2 f}{\partial x^2},\frac{\partial^2 f}{\partial y^2} < 0$ | Local maximum     |
| $\det(H) < 0$                                                                            | Saddle point      |
| $\det(H) = 0$                                                                            | Test inconclusive |
